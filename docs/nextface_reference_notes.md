# NextFace 可借鉴思路备忘

本项目不接入 NextFace，也不保留其代码。它对当前管线的参考价值主要在思路层面：

1. 可微渲染闭环  
   把几何、位姿、相机、光照和材质一起放进渲染误差里优化，而不是只依赖关键点和投影贴图。

2. 多图共享身份  
   多张同一个人的照片共享身份形状和基础反射率，每张图只单独优化表情、位姿和光照。

3. 材质分离  
   将贴图拆成 diffuse、specular、roughness，有助于减少阴影、油光和局部高光被直接烘进 albedo。

4. 纹理一致性约束  
   对多视角纹理增加一致性、平滑和左右对称约束，可作为后续减少脸周贴图错位和颜色污染的参考。

暂不采用原因：

- 使用 Basel Face Model，不是当前主线的 FLAME 拓扑。
- 依赖较老，包括 Python 3.6、PyTorch 1.3、redner/pyredner。
- 需要额外授权下载 Basel Face Model `.h5` 文件。
- GPL 许可证不适合直接复制代码进入当前项目。
