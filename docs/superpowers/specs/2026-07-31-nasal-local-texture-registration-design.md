# 鼻部局部语义纹理配准设计

## 1. 背景

`captures_20260612_135253_absolute_eye_texture_v2` 已修正相机内参与
1024 x 1024 letterbox 工作图坐标系混用的问题，并改善了闭眼纹理位置。
当前正面鼻部仍存在以下视觉问题：

- 鼻孔暗纹偏高，部分落到鼻头表面。
- 鼻翼沟暗线没有稳定贴合几何凹陷。
- 鼻头大小会被错位纹理强化或削弱。

现有证据表明，当前正面问题以纹理偏差为主：

- A2 正面鼻底几何锚点平均误差约为 4.27 px。
- v2 正面鼻部纹理控制残差为 10.09 px。
- 现有 RBF 局部场请求的最大位移约为 24.75 px。
- 为保持 Jacobian 不低于 0.35，现有局部场只应用了 70%。
- A2 与 v2 GLB 的全部顶点最大坐标差和平均距离差均为 0。

因此本阶段不改变几何，只解决鼻部纹理与固定几何之间的配准问题。

## 2. 基线锁定

本实验必须以以下 v2 产物作为只读基线：

- OBJ SHA-256:
  `50051dd20c973ed43f6511eca7b2a5ab4592438901e31da9a74a4ad3bc60201b`
- GLB SHA-256:

实验不得覆盖基线目录。运行前后都要验证上述哈希。

## 3. 目标与非目标

### 3.1 目标

- 保持 A2/v2 几何和拓扑逐顶点不变。
- 只修改鼻部拥有权掩码覆盖的 UV 像素。
- 鼻外 UV 像素与 v2 纹理逐像素一致。
- 独立对齐左右鼻孔、鼻头下缘和左右鼻翼下缘。
- 保持已改善的眼部、嘴部和脸颊纹理不变。
- 生成可离线打开的 v2 与鼻部修正版 A/B viewer。

### 3.2 非目标

- 不修改鼻梁、鼻头、鼻翼或鼻底的三维坐标。
- 不处理当前侧视图中约 20 至 25 px 的鼻部几何误差。
- 不重新烘焙整张纹理。
- 不使用依赖单个样本的手工 UV 位移。
- 不用光流直接追逐高光和阴影。

## 4. 技术方案

### 4.1 语义观测

复用已修正的投影相机和现有 MediaPipe/CelebAMask-HQ 结果，构造有固定
语义顺序的鼻部观测：

- 鼻头锚点。
- 左右鼻翼外缘。
- 左右鼻头下缘，各按弧长均匀采样。
- 左右鼻孔暗区的中心、宽度、高度和有序轮廓采样。

鼻孔检测必须保留置信度和拒绝原因。左右鼻孔必须按被拍摄者语义排序，
不得按图像文件名或相机编号猜测。

### 4.2 保序局部形变

鼻部不再使用一个自由薄板 RBF 场。改用鼻部局部坐标系中的保序形变：

1. 以鼻翼外缘和鼻头锚点建立鼻部归一化坐标。
2. 水平方向使用保持左右顺序的单调分段映射，对齐鼻翼和鼻孔宽度。
3. 垂直方向使用随水平位置变化的平滑边界偏移，对齐鼻头下缘和鼻孔高度。
4. 在鼻部外环上固定为零位移，使变形自然衰减到原纹理。
5. 只接受所有局部单元方向保持、Jacobian 为正的解。

这种表示允许左右鼻孔向相反方向展开，同时避免自由 RBF 在鼻小柱附近折叠。

### 4.3 鼻部 UV 拥有权

以固定 v2 几何的 UV 光栅化结果为基础，通过正面投影得到鼻部 UV 拥有权：

- 核心区域覆盖鼻头、鼻翼和鼻孔。
- 过渡区域只用于窄带羽化。
- 核心与过渡区域之外的纹理直接复制 v2 原像素，不经过重采样。

最终纹理计算为：

`output = base_v2 * (1 - alpha) + registered_nose * alpha`

其中 `alpha` 在核心区域为 1，在窄带过渡区域平滑变化，在鼻外严格为 0。
报告必须保存二值拥有权掩码、羽化 alpha 和鼻外像素差异统计。

### 4.4 输出

新增实验目录，不覆盖 v2：

`output/experiments/captures_20260612_135253_nasal_texture_local_v1`

至少包含：

- `meshes/face.glb`
- `textures/albedo_white.png`
- `nasal_texture_compare.html`
- `nasal_texture_report.json`
- `debug/nasal_texture/ownership_mask.png`
- `debug/nasal_texture/alpha.png`
- `debug/nasal_texture/front_controls.png`
- `debug/nasal_texture/front_registered.png`

A/B viewer 左侧固定为 v2，右侧为同几何的鼻部局部修正版。

## 5. 数据流

1. 哈希验证并读取 v2 OBJ、GLB 和纹理。
2. 加载三视角照片、预处理结果和已修正的投影相机。
3. 在正面工作图中检测有序鼻部语义观测。
4. 拟合保序鼻部局部采样场。
5. 使用固定几何重新采样鼻部候选纹理。
6. 生成鼻部 UV 拥有权和羽化 alpha。
7. 以 v2 纹理为底图，只合成鼻部 UV 区域。
8. 用原几何和新纹理导出 GLB。
9. 验证几何、鼻外像素、纹理残差和 viewer。

## 6. 失败处理

- 鼻孔检测置信度不足时，实验直接失败，不猜测鼻孔位置。
- 左右控制点顺序交叉时，实验直接失败。
- 任一局部单元翻转或 Jacobian 不为正时，实验直接失败。
- 鼻外像素出现变化时，质量门禁失败。
- 几何顶点或面片发生变化时，质量门禁失败。
- 失败不得产出标记为成功的 GLB，也不得覆盖 v2。

## 7. 测试

### 7.1 单元测试

- 鼻孔左右语义排序。
- 鼻孔轮廓弧长采样。
- 单调水平映射保持点顺序。
- 垂直边界映射不产生翻转。
- 鼻部拥有权掩码只覆盖目标区域。
- alpha 为零区域输出像素与基线逐像素一致。

### 7.2 集成测试

- v2 OBJ、GLB 和纹理运行前后哈希不变。
- 候选与 v2 的顶点最大坐标差为 0。
- 候选与 v2 的面片索引完全一致。
- 正面鼻部平均控制残差目标不高于 5 px。
- 左右鼻孔中心残差分别不高于 5 px。
- 鼻外最大像素差为 0。
- viewer 能离线加载，`viewerReady=true` 且 `viewerError=null`。

## 8. 验收顺序

1. 先查看鼻部控制点叠加图，确认观测语义正确。
2. 再查看鼻部 UV 拥有权，确认没有覆盖眼睛、嘴巴和脸颊。
3. 查看纯纹理 A/B，判断鼻孔暗纹和鼻翼沟是否对齐。
4. 查看带纹理 GLB 正面与斜侧面。
5. 本阶段通过后，再单独处理侧视鼻部几何误差。
