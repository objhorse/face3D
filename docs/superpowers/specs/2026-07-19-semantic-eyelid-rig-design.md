# 三视角语义眼睑 Rig 设计

## 目标

在不改变当前三视角采集条件、不修改用户认可的 baseline 其他部位的前提下，修复参数脸眼睑区域的扁平、夹紧和不自然凹陷。系统自动识别睁眼或闭眼，并使用同一套固定拓扑语义控制带优化眼睑、眼角和眼窝过渡。

第一阶段只验证纯几何，不重新烘焙纹理。成功标准是眼睑三维形状更自然，而不是单个二维误差更低。

## 当前根因

现有流程只通过四对 FLAME 68 点约束上下眼睑间距。当前样本正面投影眼缝约为 `2.07 px`，照片目标约为 `1.92 px`，但视觉仍然怪异。这说明眼缝距离可以准确，而上眼睑弧度、眼球方向隆起、眼角形状和眼窝过渡仍保持通用模板形状。

纹理会放大这个问题，但不是根因。闭眼睫毛贴到扁平或夹紧的眼睑表面后，会呈现刻线和凹槽感。

## 总体方案

采用“FLAME 参数脸 + 受控眼睑语义形变”两层结构：

1. 保留 baseline 的固定拓扑、身份形状、表情、相机和 UV。
2. 从固定拓扑建立左右眼的语义控制带。
3. 自动汇总三视角的睁眼/闭眼状态。
4. 只优化低维眼睑控制参数，不开放自由顶点残差。
5. 三视角共同评估眼睑轮廓和侧面隆起。
6. 使用平滑、边界固定和拓扑门禁拒绝危险候选。

## 眼部语义区域

每只眼分为三层：

- 核心带：上眼睑、下眼睑、内眼角、外眼角。
- 过渡带：眼睑到眼窝之间的一圈表面，用于连续衰减。
- 固定区：过渡带之外的眉骨、鼻根、脸颊和其他面部区域。

语义链由 FLAME 68 眼部种子点和固定拓扑上的最短路径生成。顶点索引对于所有人物保持一致，可以保存到语义区域文件并用于后续医美交互。

## 自动状态识别

复用 MediaPipe 478 点的上下眼睑距离和眼宽比例，分别判断每个视角、每只眼的状态。

- 三视角一致闭眼：使用闭眼目标。
- 三视角一致睁眼：使用睁眼目标。
- 一个侧视图冲突：降低该视角权重，以正脸和另一个一致视角为准。
- 无法形成可靠共识：不执行局部形变，保留 baseline 并报告低置信。

左右眼允许存在轻微真实不对称，但不允许一个被优化为睁眼、另一个被优化为闭眼，除非三个视角都提供一致的单侧状态证据。

## 低维控制参数

每只眼使用少量受控参数，而不是逐顶点自由位移：

- 上眼睑闭合量。
- 下眼睑闭合量。
- 上眼睑法向隆起。
- 下眼睑法向支撑。
- 内外眼角倾斜和高度微调。
- 眼窝过渡强度。

控制参数通过固定的测地距离权重传播到核心带和过渡带。过渡带外权重严格为零。候选形变只作用于最终 baseline mesh 的副本，源 OBJ 不被覆盖。

## 优化证据

每个视角使用以下证据：

- 有序上下眼睑轮廓对应。
- 内外眼角位置。
- 眼睛开口高度和面积。
- 上下眼睑弧线形状。
- 侧视图中眼睑相对眼窝的投影隆起。

三视角共享一套眼睑控制参数，相机保持冻结。正脸负责稳定宽度、弧线和左右关系，侧视图主要提供深度与隆起方向证据。

## 正则与门禁

- 核心带位移有硬上限。
- 过渡带位移随测地距离平滑衰减到零。
- 眼部之外顶点必须逐点完全不变。
- 内外眼角默认强约束，避免眼睛整体漂移。
- 使用 Laplacian/ARAP 类平滑限制局部尖坑。
- 不允许新增退化面、法线翻转或非流形边界。
- 不允许非眼部 landmark 误差恶化。
- 左右眼曲率和高度增加软一致性约束，同时保留真实不对称。

任何硬门禁失败时，Candidate 回退为 baseline，报告失败原因，不输出伪成功模型。

## 模块边界

新增模块建议：

- `src/geometry/eye_state.py`：多视角睁眼/闭眼状态和置信度汇总。
- `src/geometry/semantic_eyelid_rig.py`：语义顶点链、控制权重和低维形变。
- `src/geometry/eyelid_fit.py`：三视角目标、优化和门禁。
- `run_semantic_eyelid_experiment.py`：冻结 baseline 的纯几何实验入口。

现有 `expression_fidelity.py` 继续提供眼缝诊断，但不再作为眼睑质量的唯一指标。

## 输出

实验目录独立于 baseline，至少包含：

- `meshes/baseline_geometry.glb`
- `meshes/eyelid_candidate.glb`
- `debug/eye_state.json`
- `debug/eyelid_controls.json`
- `debug/eyelid_quality.json`
- 三视角眼部轮廓叠加图
- Baseline/Candidate 纯几何离线 Viewer
- 正面、左右侧相同机位眼部近景截图

Viewer 默认不加载纹理，使用相同相机、材质和灯光。模型切换不得改变取景和缩放。

## 测试

### 单元测试

- 睁眼、闭眼和低置信状态识别。
- 三视角冲突时的共识规则。
- 语义控制带不越过固定区。
- 控制权重连续并在边界衰减为零。
- 眼部之外顶点逐点不变。
- 折叠、退化面和法线翻转检测。

### Pipeline 测试

使用 `captures_20260612_135253`：

- 自动判断当前样本为双眼闭合。
- 在冻结 baseline 上只运行眼睑局部实验。
- 生成完整纯几何 A/B Viewer 和三视角截图。
- Candidate 眼睑曲面不得出现夹紧、尖坑或台阶。

## 验收标准

- 眼睑不再表现为两条扁平夹紧的沟。
- 闭眼时上眼睑具有自然连续弧度和轻微隆起。
- 内外眼角位置稳定。
- 眼窝过渡连续。
- 三视角轮廓整体改善。
- 眼部之外 baseline 几何完全不变。
- 拓扑质量门禁全部通过。
- 最终由同机位纯几何 A/B 视觉检查确认；单个像素指标不能单独决定成功。

## 非目标

- 第一阶段不修改纹理、UV 或颜色拼接。
- 不引入新的单目深度模型。
- 不添加逐顶点自由残差。
- 不修改鼻子、嘴巴、眉骨和整体身份形状。
- 不声明医疗级眼部测量精度。
