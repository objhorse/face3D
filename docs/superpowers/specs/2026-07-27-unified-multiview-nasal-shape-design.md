# Unified Multi-View Nasal Shape Optimization Design

## Context

The current profile-shape experiment improves one scalar: nose-tip depth relative
to the upper lip. This can correct projection depth, but it cannot describe alar
width, left-right alar asymmetry, tip roundness, or the profile curve around the
tip. Extending that experiment with more per-region thresholds would make the
pipeline subject-specific and increasingly difficult to reason about.

This design replaces that pattern with one generative nasal model and one
multi-view objective. The same model, objective, weights, and optimization
procedure must be used for every subject.

## Goals

- Recover nasal alar width and tip shape from the existing three fixed cameras.
- Preserve supported left-right asymmetry while using a weak symmetry prior to
  suppress observation noise.
- Keep FLAME fixed topology and use only low-dimensional, smooth deformation.
- Fit geometry from image boundaries, never from the baked texture.
- Use continuous confidence weighting instead of adding per-feature hard gates.
- Produce an offline same-texture A/B viewer and a pure-geometry diagnostic.

## Non-Goals

- Free per-vertex residual deformation.
- Photometric optimization using color, shadow, nostril darkness, or highlights.
- Changing expression, camera calibration, UVs, texture, or topology.
- Medical-grade dimensional accuracy.
- Subject-specific weight tuning.

## Inputs And Coordinate System

The optimizer consumes:

- Three original images and their cached semantic/face masks.
- The fixed joint-rig intrinsics and extrinsics.
- Baseline FLAME shape and frozen expression parameters.
- The baseline fixed-topology mesh and FLAME shape basis.
- FLAME semantic nose landmarks and topology.

All model vertices are generated in the FLAME model frame and transformed into
each calibrated camera frame only for projection. Camera parameters remain
frozen during nasal optimization, preventing geometry and camera pose from
explaining the same error.

## Observation Model

### Front View

The front image contributes a nasal boundary confidence field rather than
detector landmark coordinates. The field represents:

- Subject-right and subject-left outer alar boundaries.
- Total alar width.
- Each side's half-width relative to the nasal centerline.
- The lower tip and alar transition boundary when visible.

The centerline comes from stable upper-face evidence and the calibrated baseline
projection, not from enforcing a perfectly symmetric nose.

### Side Views

Each side image contributes a local profile distance field around the nose. It
covers multiple vertical samples through:

- Upper tip transition.
- Tip apex.
- Lower tip transition.
- Visible alar-to-tip transition.

This replaces the single nose-tip extremum with a curve observation. Epipolar
geometry and the projected baseline nose define the search region; the actual
image boundary defines the target.

### Confidence

Each observation pixel receives a continuous confidence weight derived from:

- Stability under small mask erosion and dilation.
- Agreement between semantic boundary and local image gradient.
- Visibility and view angle.
- Distance from uncertain nostril shadow, highlight, or occlusion regions.
- Cross-view support under the fixed rig.

Uncertain evidence contributes less to the objective. It is not accepted or
rejected by a growing list of hand-tuned thresholds.

## Generative Nasal Model

The optimized parameter vector contains:

1. A regularized FLAME shape update.
2. A compact semantic nasal parameter vector:
   - Shared alar width.
   - Left-right alar width asymmetry.
   - Shared alar depth.
   - Left-right alar depth asymmetry.
   - Tip depth.
   - Tip vertical position.
   - Tip roundness.
   - Tip-to-alar transition fullness.

Semantic deformation bases are built from FLAME nasal seeds using geodesic
topology weights. They have compact support, smooth falloff, and zero direct
support on the mouth, philtrum, eyes, jaw, and chin. The bases are orthogonalized
against each other as far as practical so that width, depth, and roundness do not
compete through redundant controls.

The semantic basis is not a free residual. Every candidate is generated by the
same small set of anatomically interpretable parameters.

## Unified Objective

The complete candidate is optimized against one robust MAP objective:

```text
E(theta) =
    E_front_boundary(theta)
  + E_left_profile(theta)
  + E_right_profile(theta)
  + lambda_shape * E_FLAME_prior(theta)
  + lambda_semantic * E_semantic_prior(theta)
  + lambda_smooth * E_surface_smoothness(theta)
  + lambda_symmetry * E_weak_symmetry(theta)
```

The three image terms compare rendered nasal boundaries to confidence-weighted
distance fields using a robust loss. The priors resolve ambiguity that three
views cannot observe:

- `E_FLAME_prior` keeps identity parameters statistically plausible and near the
  MICA/baseline estimate when image evidence is weak.
- `E_semantic_prior` discourages unnecessarily large semantic controls.
- `E_surface_smoothness` penalizes bending and local normal discontinuity.
- `E_weak_symmetry` suppresses unsupported asymmetry without erasing
  asymmetry consistently observed in the images.

There is no sequential "fix width, then patch tip" behavior. Coarse-to-fine
evaluation may be used for numerical efficiency, but every level optimizes the
same objective and parameterization.

Because the parameter count is small, the first implementation may use a robust
least-squares optimizer with finite-difference Jacobians. This avoids introducing
a new differentiable-rendering dependency before the observation model is
validated.

## Optimization Flow

1. Load baseline parameters, fixed cameras, and semantic masks.
2. Build front and side confidence-weighted distance fields.
3. Construct the low-dimensional semantic nasal basis.
4. Initialize all updates at zero, preserving the baseline exactly.
5. Jointly optimize FLAME shape and semantic nasal parameters.
6. Generate the candidate mesh with frozen expression and cameras.
7. Export the candidate with the exact baseline texture.
8. Render pure-geometry overlays and the offline A/B viewer.

If reliable image evidence is absent, the priors naturally keep the solution
near the baseline. The system does not require a separate rule for every missing
feature.

## Validity Checks

Hard checks are limited to candidate validity:

- All parameters and vertices are finite.
- Mesh topology and face count are unchanged.
- No new flipped, degenerate, or non-manifold faces are introduced.

Image fit, asymmetry, locality, and smoothness are objective terms and reported
metrics, not post-hoc feature-specific pass/fail patches.

## Diagnostics And Outputs

Each experiment produces:

- `nasal_observations.json`: observed fields, confidence summaries, and camera
  references.
- `nasal_fit_report.json`: objective terms before and after optimization,
  optimized parameters, and iteration history.
- `nasal_geometry_diagnostic.html`: three original images with observed and
  projected pure-geometry boundaries.
- `nasal_shape_compare.html`: offline baseline/candidate A/B viewer using the
  same texture.
- Candidate GLB with unchanged topology, UVs, and texture.

The diagnostic must clearly separate image observations, baseline projections,
and candidate projections. Texture is never displayed in the geometry
observation overlays.

## Testing

### Unit Tests

- Distance-field construction preserves subject-left/right semantics.
- Confidence decreases for unstable mask boundaries and image/mask
  disagreement.
- Each semantic parameter moves only its intended anatomical mode.
- Asymmetry controls preserve sign and do not swap subject-left/right.
- Zero parameters reproduce the baseline exactly.
- The unified objective decreases for a synthetic known nasal deformation.
- Smoothness and weak symmetry priors behave continuously.

### Integration Tests

Run the identical configuration on:

- `captures_20260612_135253`, where the baseline is already close and should
  receive little unsupported deformation.
- `captures_20260612_140210`, where the current profile experiment improved tip
  depth but still lacks correct alar width and tip shape.

For both datasets, verify fixed cameras, expression, topology, UVs, and texture.
Compare objective terms, pure-geometry overlays, and same-texture A/B viewers.
No dataset-specific optimization weights are permitted.

## Acceptance

The experiment is successful when:

- The same optimizer and configuration run on both datasets.
- Front alar and bilateral tip-profile evidence are represented by the candidate
  more faithfully than by the baseline in the diagnostic overlays.
- The candidate remains a valid fixed-topology mesh.
- Visual improvement can be judged in an offline same-texture A/B viewer.
- No free residual, texture loss, camera adjustment, or subject-specific patch
  participates in the result.
