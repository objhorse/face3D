# Baseline 正脸五官分区语义纹理配准设计

## 1. 背景与结论

用户已确认 `captures_20260612_135253_controlled_identity_v1` 的 Baseline 几何比后续轮廓候选更像本人。后续工作停止修改该几何，优先解决正脸纹理中的鼻孔、眼睑和嘴唇错位。

当前纹理配准虽然把控制点残差从约 `9.79 px` 降到 `1.28 px`，但这个数字不能代表五官贴准。鼻部控制点通过最近邻边界匹配生成，可能发生左右混配、重复匹配和控制线交叉；眼睛、鼻子和嘴又共用一个全局 RBF 形变场，一个区域的修正会牵动其他区域。这是最终贴图仍错位的主要原因。

采用方案 B：冻结 Baseline 几何，在正脸照片上执行分区、带顺序约束的局部语义配准。第一阶段只要求正脸五官准确；左右照片负责侧脸纹理和非五官接缝，不覆盖正脸五官核心。

## 2. 冻结基准

实验固定使用以下产物：

- 数据集：`D:/face3D/captures_20260612_135253`
- Baseline：`output/experiments/captures_20260612_135253_controlled_identity_v1`
- 几何：`meshes/face_mesh.obj`
- 相机：`meshes/cameras.json`
- 原始对照：`meshes/face.glb`

冻结校验值：

- `face_mesh.obj` SHA-256：`ED1CC8B48AFB781788B4D0AC11F5F84F9169AE81CB39E57CA4EF74AE2BE2BF5E`
- `cameras.json` SHA-256：`36F7D0D2AD7E7E8F2B2812EAEB103C26A1A18C569402B21CAC39E28AB596C65C`
- Baseline `face.glb` SHA-256：`B17558815F862DA9EE86999551294D082C316BBF8CEE1CD3219638B8AE311860`

纹理实验不得重新运行 MICA、FLAME 拟合、相机优化、轮廓优化或任何顶点变形。输出模型的顶点、面片、UV 和相机文件必须与冻结基准一致。

## 3. 目标与非目标

### 目标

- 鼻翼、鼻孔、眼睑、嘴唇纹理落在对应几何位置。
- 一个五官的修正不拖动其他五官。
- 正脸五官核心只使用正脸照片。
- 保留现有多视角颜色归一化和接缝融合能力。
- 生成可解释的分区误差、形变场和带纹理 A/B 对比。

### 非目标

- 不修改 Baseline 脸型、鼻形、嘴形或表情。
- 不在本阶段优化侧脸五官。
- 不使用自由稠密光流覆盖整张脸。
- 不用纹理误差反向评价或修改三维几何。

## 4. 方案结构

### 4.1 语义观测

新增 `src/appearance/semantic_feature_registration.py`，为正脸构造独立观测：

- 眼睛：左右眼角、上眼睑、下眼睑，按眼角到眼角的弧长顺序采样。
- 嘴：左右嘴角、上唇、下唇和可见内唇边界，按左右及上下语义保持顺序。
- 鼻：鼻翼左右边界、鼻头下缘和鼻孔暗区。鼻翼按图像行分别提取左边界与右边界；鼻孔按左右连通区域和中心线分类。

模型侧使用投影后的 FLAME 语义区域、68 点锚点和鼻部左右关系。照片侧使用 MediaPipe、face parser 标签和鼻部局部灰度边缘。任何对应关系都必须保持左右、上下和曲线顺序，禁止最近邻自由配对。

观测置信度不足时只关闭该局部修正，不能用其他五官的形变场代替。

### 4.2 两级纹理采样校正

第一级是正脸整体微调，只允许小幅二维相似变换：

- 平移不超过 `8 px`（以 `1024x1024` 工作图计）。
- 旋转不超过 `1.0` 度。
- 尺度变化不超过 `1.5%`。

第二级为三个互相独立的局部形变场：眼区、鼻区、嘴区。每个形变场仅在对应语义核心内生效，并在外围过渡环中平滑衰减到零。局部最大位移默认 `16 px`，不允许影响另一个五官核心。

局部场采用有界平滑插值，并检查采样映射的 Jacobian。出现折叠、左右翻转或超限位移时，该区域回退到整体微调结果。

### 4.3 多视角纹理所有权

正脸五官核心区域的正脸采样权重固定为主导：

- 眼睛、鼻子和嘴的核心区域，正脸来源权重至少 `95%`。
- 左右视图在核心区域权重置零或接近零。
- 核心外设置羽化过渡环，再恢复现有法线角度和可见性加权。
- 颜色归一化继续在五官掩码外估计，避免唇色、鼻孔和眼睑污染肤色统计。

该策略只改变纹理采样坐标和视图混合权重，不改变 UV 或几何。

## 5. 数据流与接口

新增实验入口 `run_baseline_texture_registration_experiment.py`：

1. 校验 Baseline 文件哈希。
2. 加载冻结的 OBJ、UV 和相机。
3. 预处理三张原图，但不运行几何 pipeline。
4. 提取正脸分区语义观测。
5. 估计整体微调和三个局部采样场。
6. 使用修改后的 `sampling_warps` 与 `feature_masks` 重新烘焙纹理。
7. 导出新的 `face.glb`、配准报告和离线 A/B Viewer。
8. 再次校验导出前后的几何、面片和 UV 未改变。

现有 `run_stable_texture_pipeline` 和 `module3_texture.py` 保持兼容。实验先通过配置启用：

- `STABLE_TEXTURE_REGISTRATION_MODE = "semantic_local_v2"`
- `STABLE_TEXTURE_LOCK_BASELINE_GEOMETRY = True`
- `STABLE_TEXTURE_FRONT_FEATURE_OWNERSHIP = True`

旧的全局 RBF 模式保留为 legacy，不作为本实验默认候选。

## 6. 诊断与验收

每个五官分别输出：

- 模型语义边界与照片边界叠加图。
- 有顺序的对应线，左右和上下使用不同颜色。
- 局部位移热图和影响范围图。
- 配准前后对称 Chamfer 距离。
- 鼻孔左右中心、宽度和高度误差。
- 嘴角及眼角误差。
- 形变 Jacobian 最小值、P95 位移和最大位移。

候选必须同时满足：

- Baseline OBJ、面片、UV 和相机哈希不变。
- 眼区、鼻区、嘴区的边界误差均改善至少 `20%`，任何区域不得用总平均分掩盖退化。
- 鼻孔左右顺序正确，不出现交叉对应。
- 每个五官关键锚点 P90 误差不高于 `4 px`。
- 局部最大位移不高于 `16 px`，P95 不高于 `10 px`。
- 采样场最小 Jacobian 大于 `0.35`，不存在折叠。
- 正脸五官核心的正脸来源比例至少 `95%`。
- 带纹理 Viewer 中 Baseline 与候选使用完全相同的几何和相机归一化。

自动指标通过后仍需人工确认“更像本人”。人工判断优先于未被证明有效的混合总分。

## 7. 测试

### 单元测试

- 有序曲线匹配不会左右交换或交叉。
- 三个局部场在其他五官核心内位移为零。
- 整体微调和局部位移均受上限约束。
- Jacobian 门禁能拒绝折叠场。
- 正脸五官所有权阻止侧视图覆盖核心区域。
- 几何哈希门禁能拒绝任何顶点、面片、UV 或相机变化。

### 实验测试

- 在冻结的 `135253` Baseline 上只重跑纹理。
- 生成鼻、眼、嘴分项诊断和带纹理 A/B Viewer。
- 对鼻孔、眼睑和嘴唇分别截取正脸近景。
- 保留旧纹理作为对照，不覆盖 Baseline 产物。

## 8. 实施顺序

1. 建立冻结 Baseline 加载和哈希门禁。
2. 实现有序语义观测与分项诊断，不先改纹理。
3. 实现小幅整体微调。
4. 按鼻子、嘴、眼睛顺序加入独立局部场。
5. 加入正脸五官纹理所有权。
6. 仅重跑纹理并生成 A/B Viewer。

第一轮重点验证鼻翼与鼻孔。只有鼻部观测和局部场通过门禁，才继续启用嘴和眼睛，避免再次把多个问题混进一个分数。
